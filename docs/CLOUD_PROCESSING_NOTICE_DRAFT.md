# OpenAI資料處理告知（DRAFT）

本文件是RentProof雲端分析的處理告知草案，尚未取代正式隱私政策或法律審閱。

## 會傳送的內容

只有在使用者建立案件時明確同意，RentProof才會把完成格式、安全與權限檢查後的必要內容傳送至OpenAI Responses API，例如租屋廣告畫面、看屋照片的處理後版本，以及租約中可定位的文字頁面。

## 處理目的

OpenAI只用於抽取設備、費用、屋況描述、契約條款及來源位置的候選資料。支持／矛盾／證據不足、官方規則結果、金額運算、風險訊號與行動優先順序仍由RentProof Server的確定性程式產生。

## 不會傳送的內容

RentProof不會把帳戶密碼、登入Cookie、驗證碼、API Key、資料庫密碼或本機檔案路徑傳送給模型。偵測到認證秘密、完整金融帳號或private key時停止處理；看屋影像不使用臉部辨識。

## 保存與刪除

每次OpenAI請求設定`store: false`，但這不等同於OpenAI提供Zero Data Retention。RentProof保存政策依案件類型與隱私政策草案執行；使用者刪除案件後立即停止一般存取，目前展示環境會移除加密素材並清除線上案件內容。正式服務的備份、營運者資訊、處理地區及部分保存期限仍須在上線前完成。

## 使用者選擇

不同意這項處理時，仍可閱讀服務說明，但無法建立需要OpenAI分析的案件，資料也不會送往OpenAI。已建立案件可由使用者刪除；撤回同意後不再發出新的模型請求。
